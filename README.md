# Doctors Without Borders - WEDE5020 Part 2 and 3
Student: Jawaad Ganief | Course: WEDE5020

## Project Overview
5-page website for MSF: Home, About, Where We Work, Enquiry, Contact.

## Part 2 Fixes Based on Part 1 Feedback
1. Created external style.css and linked via <link rel="stylesheet" href="style.css"> in all 5 pages
2. Added CSS reset, base style, typography scale, Flexbox/Grid layout
3. Added hover, focus, active pseudo-classes for interactive elements
4. Added responsive design: media queries at 768px and 480px, relative units (rem/%), responsive images with srcset and picture element
5. Tested with browser dev tools and included screenshots in this README

## File Structure
- index.html - Home with overview and responsive image
- about.html - About MSF + gallery lightbox
- where-we-work.html - Interactive Google Map
- enquiry.html - Enquiry form with validation + search
- contact.html - Contact form with validation
- style.css - External stylesheet (responsive)
- script.js - Lightbox, search, form validation

## How to Run
Open index.html in browser or deploy via GitHub Pages.

## Interactive Features
- Search bar filters content live
- Gallery images open in lightbox
- Map is interactive (zoom/drag)
- Forms validate and show success/error messages
